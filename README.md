# SmartKids — дитячий навчальний портал

## 1. Опис проєкту
Навчальний проєкт (лабораторна робота №9), створений у межах навчання у Чернівецькому політехнічному фаховому коледжі. Мета проєкту — побудова двовимірного адаптивного макета вебсторінки за допомогою CSS Grid Layout.

## 2. Функціонал та результати
- Реалізовано шапку сайту (header), головну секцію з анонсом та сітку переваг.
- Створено стилізований візуальний макет мобільного пристрою всередині сторінки.
- Застосовано адаптивні медіа-запити (`@media`) для коректного відображення на різних екранах.

## 3. Використані технології
- HTML5, CSS3
- CSS Grid Layout (`grid-template-areas`, `grid-template-columns`)
- Система контролю версій: Git, GitHub

## 4. Як переглянути
Ви можете переглянути вихідний код у цьому репозиторії (`index.html` та `styles.css`) або відкрити сторінку через GitHub Pages.
